# カリキュラム全体像（約 50 時間）

最終目標: **CD-SEM 画像の寸法計測を壊さないノイズ低減の前処理**を、原理から理解して設計できること。

学習方針:
- 主要処理は **まず自作 → OpenCV と比較**。入出力・表示・FFT 本体・バイラテラル/NLM は OpenCV を使う。
- データはすべて**合成**（`generate_dataset`）。真値が既知なので CD 計測誤差で評価できる。
- 数式は**直感重視**。導出より「何のための操作か」を図と実験で理解する。

経験者は各セクションを下限で通過するため、実効は約 50h に収まる見込みです。
50h を超えそうな場合の**調整弁**は次の順で使います:

1. セクション 9（フーリエ）を「観察のみ・自作ノッチは任意」に圧縮。
2. セクション 10 をセクション 4〜6 の中に吸収。
3. 予備 2h を削らず、詰まり対応に確保する。
