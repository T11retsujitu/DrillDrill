# ノイズ低減結果の評価

「ノイズが減った」だけでは不十分です。CD-SEM では **計測を壊さずにノイズを減らせたか**が問われます。
本教材では次の 3 層で評価します。

## 1. 定量指標（真値がある合成データ）

合成データは「ノイズなしの理想画像（clean）」が既知なので、参照ありの指標が使えます。

- **PSNR [dB]**: 誤差の大きさ。高いほど clean に近い。ただし人間の見え方や構造保存とは必ずしも一致しない。
- **SSIM**: 構造の類似度（0〜1、1 が理想）。局所的な輝度・コントラスト・構造の相関を見る。

`dd::psnr` / `dd::ssim` を使います。

> 注意: PSNR/SSIM が高くても、エッジがなまって**線幅がずれる**ことがあります。指標だけで判断しないこと。

## 2. 定性確認

- **ラインプロファイル** (`dd::line_profile`): 特定行の画素値の並びをプロットし、エッジの鋭さ・
  縞ノイズの残存を目で確認する。平滑化のかけ過ぎはプロファイルの「肩」がなまることで分かる。
- **残差画像** (noisy − denoised): 除去された成分にエッジ（構造）が混ざっていないか確認する。
  構造が残差に出ていたら、それは「消してはいけない情報」を消している。

## 3. タスク指向評価（本命）

最終的な解析目的に対して良くなったかを測ります。CD-SEM では:

- **CD（線幅）計測誤差**: エッジ位置を検出して線幅を求め、真値との差を比較する。
- **エッジ位置バイアス**: 平滑化でエッジが系統的にずれていないか。
- **ラフネス（LER/LWR）の保存**: 平滑化しすぎると真のエッジラフネスまで消えてしまう。
  ノイズ由来のラフネスと真のラフネスを区別できているか。

合成データはエッジ座標・線幅の**正解**（`ground_truth.yml`）を持つので、これらを定量化できます。
評価の実装はセクション 11 と最終課題で扱います。

## 評価の落とし穴

- **PSNR/SSIM だけを最大化しない**。計測目的に対して最適とは限らない。
- **強い平滑化は必ず情報を失う**。「ノイズ↓・計測誤差↑」のトレードオフを常に確認する。
- **単一指標・単一画像で結論しない**。複数のノイズ強度・複数手法で比較する。
