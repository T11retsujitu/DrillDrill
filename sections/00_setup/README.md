# セクション 00 — 環境構築とビルド

## 1. 学習目標
- WSL 上で C++17 + OpenCV + CMake のプロジェクトを **ビルドして実行できる**。
- コンパイルとリンクの違い、ヘッダとソースの分担を説明できる。
- 画像を 1 枚生成して PNG に保存できる。

## 2. 前提知識
- なし（[docs/setup.md](../../docs/setup.md) の環境構築が済んでいること）。

## 3. 推定所要時間
- 約 4 時間（環境構築の待ち時間を含む）。

## 4. 最小限の理論
- **コンパイル**: 各 `.cpp` を機械語（`.o`）に変換する工程。文法エラーはここで出る。
- **リンク**: 複数の `.o` とライブラリ（OpenCV）を結合して実行ファイルを作る工程。
  `undefined reference` はここで出る＝「宣言はあるが実体が見つからない」。
- **ヘッダ (.hpp)** は宣言、**ソース (.cpp)** は定義。利用側はヘッダを `#include` する。
- CMake は「どのソースをどのライブラリとビルドするか」を記述する。

## 5. 動作を予測する問題
- `make_first_image()` が返す `cv::Mat` の `type()` はいくつになる？（`CV_8U` の数値は？）
- ヘッダに宣言だけ書いてソースに定義を書かなかったら、エラーは**コンパイル時**と
  **リンク時**のどちらで出る？

## 6. 実装課題
- `src/first_image.cpp` の `make_first_image()` を実装する。
- 要件: **空でない 256x256 の 8bit (CV_8U) 1ch 画像**を返すこと。中身は何でもよい
  （このセクションの目的は環境確認）。`dd::synth::make_line_space` を使うと簡単。

## 7. コンパイル・実行
```bash
cmake -S . -B build && cmake --build build -j
./build/sections/00_setup/sec00_demo out00.png
```
`size = 256x256 ...` と表示され、`out00.png` が作られれば成功。

## 8. テスト・確認
```bash
ctest --test-dir build -R drill.sec00 --output-on-failure
```
実装前は赤、正しく実装すると緑になる。

## 9. 結果の観察
- `out00.png` を Windows 側で開いて表示できるか確認する（画像確認の練習）。

## 10. OpenCV 実装との比較
- このセクションでは比較なし（環境確認が目的）。

## 11. 考察問題
- `undefined reference to 'cv::imwrite'` が出たとき、原因はコンパイルとリンクのどちら？
  どの CMake の記述で解決する？

## 12. 発展課題
- `make_first_image()` の中身を、線の太さ（duty）を変えて 2 種類作り分けてみる。
