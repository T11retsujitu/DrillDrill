# セクション 02 — コピー・参照・RAII

## 4. 最小限の理論
- `cv::Mat b = a;` は **浅いコピー**。ヘッダ（サイズ等）だけ複製し、画素データは共有する。
  どちらか経由で書き換えると両方変わる。
- `a.clone()` は **深いコピー**。データ本体まで複製する。独立に書き換えられる。
- `a(cv::Rect(...))` の **ROI** もデータを共有する（元画像の一部を指す窓）。
- **参照カウント**: 共有データは「何個の Mat が参照しているか」を数え、最後の Mat が
  スコープを抜けた（**RAII**）ときに自動解放される。`delete` は不要。
- Python の「代入は参照」と似ているが、`clone()` で明示的に切り離せる点を意識する。

## 5. 動作を予測する問題

- ROI `a(cv::Rect(0,0,2,2))` を書き換えると `a` は変わる？
