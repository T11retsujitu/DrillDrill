# セクション 08 — 二値化とモルフォロジー

「想定した形に作れているか」を測る第一歩は、画像を**前景/背景に分ける**こと。
このセクションで初めて、線幅（CD）を数値として測る。

## 1. 学習目標
- 固定しきい値と大津の方法（自動しきい値）を自作できる。
- 収縮・膨張・オープニング・クロージングの効果を予測して使い分けられる。
- 「前処理 → 二値化 → 形状整形 → 計測」の流れを体験し、各段階が計測値に与える影響を観察する。
- 関数の合成（open = erode→dilate）と、セクション 03 の成果の再利用を体験する。

## 2. 前提知識
- **セクション 03 の `compute_histogram` が完成していること**（大津法で再利用する）。
- セクション 05（前処理としての平滑化）。

## 4. 最小限の理論
- **二値化**: `v > t` を前景(255)、それ以外を背景(0) にする。すべては t の選び方。
- **大津の方法**: ヒストグラムを 2 クラスに分け、**クラス間分散**
  σ_B²(t) = ω0·ω1·(μ0−μ1)² が最大になる t を選ぶ。双峰性のヒストグラム
  （ライン/スペースのような 2 値的対象）に強い。
- **モルフォロジー**（二値画像の形状操作）:
  - 収縮 erode = 近傍の min。白が痩せる。孤立した白ノイズが消える。
  - 膨張 dilate = 近傍の max。白が太る。小さな黒穴が埋まる。
  - **オープニング** = erode→dilate。白ノイズ除去。太いバンドは元の幅に戻る。
  - **クロージング** = dilate→erode。黒穴埋め。
- 重要な性質: 構造要素(3x3)より**細い**構造はオープニングで消える。
  「ノイズを消す操作」は「細い線も消す操作」でもある（CD-SEM の細線に直結）。

## 5. 動作を予測する問題
- 値がちょうど t の画素は前景・背景どちらになるか（`>` と `>=` の違い）。
- 孤立した白 1 画素に erode3 / dilate3 をかけるとそれぞれどうなる？
- 幅 8 の白バンド + 孤立 salt に open3 をかけると、バンドの幅は変わる？ salt は？
- ノイズ画像を「直接二値化」すると、線の縁はどう見える？

## 6. 実装課題
`src/binarize.cpp` の 6 関数を実装する（仕様は `include/binarize.hpp`）。

1. `threshold_binary(src, thresh)` — `v > thresh ? 255 : 0`。
2. `otsu_threshold(src)` — `compute_histogram` を**再利用**し、σ_B² 最大の t を返す。
   ヒント: 全体の輝度和を先に求めれば、t のループ内は逐次更新だけで書ける（O(256)）。
3. `erode3` / `dilate3` — 3x3 近傍の min / max（境界は replicate）。
   min 版と max 版はほぼ同じコードになる。共通化の方法を考えてみる。
4. `open3` / `close3` — erode/dilate の合成 1 行ずつ。

- `erode3`/`dilate3` ↔ `cv::erode`/`cv::dilate`（3x3 矩形、テストで完全一致）。
  `cv::morphologyEx(MORPH_OPEN/CLOSE)` も試す。
- 中央値との比較: open3 と median 3x3 は、二値画像に対してどう違うか実験する。

## 11. 考察問題
- 大津法はどんなヒストグラムで失敗するか（単峰・面積比が極端・照明ムラ）。
- 平滑化→二値化で線幅が系統的にずれる（バイアスする）ことがあるのはなぜか。
  エッジの「肩のなまり」としきい値の位置関係で説明せよ。
- オープニングで消えない最小の構造サイズは？ 5x5 構造要素ならどうなる？
- 「二値化してから形を直す」のと「二値化の前に画像を平滑化する」のは何が違うか。
  CD 計測ではどちらを選ぶべきか。
