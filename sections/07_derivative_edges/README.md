# セクション 07 — 微分フィルタとエッジ

CD 計測は「エッジがどこにあるか」を測る作業。このセクションはその土台になる。

## 1. 学習目標
- 差分・Sobel・ラプラシアンをカーネルとして理解し、`convolve` で実装できる。
- 微分出力が**符号付き**であることと、CV_32F で持つ理由を説明できる。
- 勾配強度によるエッジ検出と、**微分がノイズを増幅する**ことを確認できる。
- エッジ位置（勾配ピーク）と CD 計測の関係を説明できる。

## 2. 前提知識
- **セクション 04 の `convolve` が完成していること**（本セクションはそれを再利用する）。
- セクション 05（平滑化。「平滑化→微分」の比較に使う）。

## 3. 推定所要時間

## 4. 最小限の理論
- **差分 = 微分の離散版**: 隣との差 `[-1, +1]` が最も素朴な微分。ノイズも差になるので増幅される。
- **Sobel**: 微分（横）と平滑化（縦）を組み合わせた 3x3 カーネル。
  「微分したい方向と直交する方向に平滑化」でノイズ増幅を抑える。
- **勾配強度** `|∇I| = sqrt(gx² + gy²)`: 方向によらないエッジの強さ。
- **ラプラシアン**: 2 階微分。エッジで符号が反転（ゼロ交差）。ノイズにはさらに敏感。
- **符号の意味**: `sobel_x > 0` は「左が暗く右が明るい」。エッジの**向き**の情報であり、
  8bit に丸めると失われる（セクション 04 の教訓）。

## 5. 動作を予測する問題
- 平坦な画像（全画素 120）に Sobel をかけると出力は？
- 左 0 / 右 100 の垂直ステップに `sobel_x` をかけたとき、エッジ列の値はいくつになるか
  手計算せよ（カーネルの重み和を考える。テストと同じ値になる）。
- 明→暗のエッジでは符号はどうなる？ `sobel_y` は垂直エッジに反応する？

## 6. 実装課題
`src/edges.cpp` の 4 関数を実装する（仕様は `include/edges.hpp`）。

1. `sobel_x` / `sobel_y` — カーネルを `cv::Mat_<float>` で定義し `convolve` を呼ぶ。
2. `gradient_magnitude(gx, gy)` — 要素ごとに `sqrt(gx²+gy²)`（ループでも `cv::magnitude` でもよい）。
3. `laplacian4` — 4 近傍ラプラシアンカーネルで `convolve`。

## 11. 考察問題
- なぜ「平滑化してから微分」するのか。平滑化しすぎるとエッジ位置の推定はどうなるか
  （鋭さと位置精度のトレードオフ。CD 計測にどう効くか）。
- ラプラシアンが Sobel よりノイズに弱いのはなぜか。
- 勾配ピークの位置は画素単位でしか分からない。サブピクセル精度で求めるには
  どんな方法が考えられるか（最終課題への伏線）。

## 12. 発展課題
- Prewitt（平滑化部が [1,1,1]）を実装し、Sobel とノイズ耐性を比較する。
- 中央行の |gx| プロファイルに放物線フィッティングして、ピーク位置をサブピクセルで推定する。
- 「ガウシアン平滑化＋微分」を 1 つのカーネル（DoG: Derivative of Gaussian）にまとめて
  1 回の `convolve` で済ませる。
