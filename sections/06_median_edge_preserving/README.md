# セクション 06 — 非線形フィルタとエッジ保存平滑化

## 1. 学習目標
- メディアン（中央値）フィルタを自作し、**線形フィルタとの本質的な違い**を説明できる。
- 「インパルスノイズにはメディアン」「エッジを壊さない平滑化」の理由を説明できる。
- OpenCV のバイラテラル・NLM を**比較対象**として使い、エッジ保存性を観察できる。
- STL アルゴリズム（`std::nth_element`）と計算量を意識した実装ができる。

## 2. 前提知識
- セクション 05（平滑化の基礎とトレードオフ）。

## 3. 推定所要時間
- 約 4 時間。

## 4. 最小限の理論
- **メディアンフィルタ**: 近傍の値を並べて**中央値**を出力する。平均と違い、
  外れ値（インパルス）に引きずられない（中央値のロバスト性）。
  また、理想的なステップエッジでは近傍の過半数が同じ側になるため、
  **中間値を作らずエッジを保つ**。これは「重み付き和」では原理的にできないこと。
- **線形 vs 非線形**: 畳み込み（重み付き和）で書けるフィルタは線形。メディアンは
  並べ替えを使うので**非線形**であり、セクション 04 の `convolve` では実装できない。
- **エッジ保存平滑化**: バイラテラルフィルタは「近くて**明るさも近い**画素だけ」を平均する。
  NLM（Non-Local Means）は「似たパターンの場所」を画像全体から探して平均する。
  どちらも計算コストと引き換えにエッジ保存性を高める。本教材では**自作せず** OpenCV 実装を
  比較対象として使う（原理の理解と使い分けが目標）。
- 計算量: 素朴なメディアンは 1 画素あたり O(k² log k²)（ソート）。`std::nth_element` なら
  平均 O(k²)。OpenCV の 8bit メディアンはヒストグラム法でさらに速い。

## 5. 動作を予測する問題
- 全画素 50 の画像の中央 1 画素だけ 255 のとき、3x3 メディアンの出力は？ 3x3 box なら？
- 理想的な垂直ステップエッジ（0|200）に 3x3 メディアンをかけると、エッジ位置の画素は
  どうなる？ ガウシアンとの違いは？
- 5% のインパルスノイズに対して、メディアンとガウシアンのどちらが PSNR で勝つか？

## 6. 実装課題
`src/median.cpp` の `median_filter(src, ksize)` を実装する（仕様は `include/median.hpp`）。

- CV_8U 入力 → CV_8U 出力。境界は replicate（セクション 04 と同じ `std::clamp` 方式）。
- 近傍 k×k 個を `std::vector<uchar>` に集め、`std::nth_element` で中央値を取る。
- バッファはループの外で 1 回だけ確保して使い回す（毎画素 `new` しない）。

## 9. 結果の観察
- `sec06_impulse_median3.png` と `sec06_impulse_gauss3.png`: ガウシアンはインパルスを
  「薄く広げる」だけで消せていないことを拡大して確認する。
- `sec06_profiles.csv` をプロットし、エッジの肩（立ち上がり）が
  median / gauss / bilateral / NLM でどう違うかを見る。
- bilateral と NLM の結果で、ライン内部の平坦さとエッジの鋭さを比べる。

## 10. OpenCV 実装との比較
- `median_filter` ↔ `cv::medianBlur`（テストで完全一致を確認する。中央値は一意なので
  「ほぼ一致」ではなく**完全一致**が期待できる。丸め誤差が出ないのはなぜか考える）。
- 実行時間を比べる。OpenCV のヒストグラム法がなぜ速いか調べる（発展）。

## 11. 考察問題
- メディアンが `convolve`（重み付き和）で書けないのはなぜか。
- メディアンはどんな構造を壊すか？ ライン幅がカーネルより**細い**とき何が起きるか
  （CD-SEM で細線パターンに大きいメディアンをかける危険）。
- バイラテラルの `sigmaColor` を極端に大きくすると何フィルタと等価になるか。
- CD 計測の前処理として、メディアン・ガウシアン・バイラテラルをどう使い分けるか。

## 12. 発展課題
- ksize=3,5,9 で細線（duty を小さくしたパターン）に適用し、線が「消える」条件を実験する。
- 重み付きメディアン・擬似メディアン（separable median）を調べる。
- `cv::medianBlur` と自作の実行時間を ksize を変えて比較し、計算量の差を体感する。
