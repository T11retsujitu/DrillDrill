# 最終課題 — CD-SEM パターンの寸法計測とノイズ低減の評価

> 全セクション（0〜12）を終えてから取り組みます。推定 6 時間。
> 現状はこの課題**仕様**のみを提供します。スターター一式はセクション実装の完了後に追加します。

## 必修課題 A — 「計測を壊さない前処理」を選ぶ

### 目的
ノイズ低減が **CD（線幅）計測・エッジ位置・ラインエッジラフネス**にどう影響するかを定量化し、
「PSNR/SSIM を上げること」ではなく「計測目的に対して最適な前処理」を根拠付きで選べるようになる。

### 入力画像
- `generate_dataset` が生成する合成ライン&スペース（真の線幅・エッジ座標が既知）。
- ノイズ強度を複数用意する（低ドーズ〜高ドーズ相当）。

### 想定ノイズ
- Poisson（ショット）＋ Gaussian（読み出し）を主とする。任意で走査線ノイズを追加。

### 実装する処理
- 自作: 平均化 / ガウシアン / メディアン（セクション 5・6 の成果を再利用）。
- OpenCV: バイラテラル / NLM（エッジ保存の比較対象）。
- 各手法の後に、エッジ検出 → エッジ位置 → 線幅（CD）を算出するパイプライン。

### 比較対象
- 無処理 vs 各平滑化。特に **単純平滑化 vs エッジ保存平滑化**。

### 評価方法
1. 参照あり指標: PSNR / SSIM。
2. **タスク指向**: CD 計測誤差（|測定線幅 − 真値|）、エッジ位置バイアス、ラフネスの過小評価量。
3. 定性: ラインプロファイル・残差画像。

### 完成条件
- 「ノイズは減るが計測が狂う」トレードオフを**表**で提示する。
- ノイズ強度ごとに推奨手法とパラメータを、根拠付きで結論する。
- レポート（Markdown）＋ 再現可能なコード。

### 難易度 / 実務接続
- 中〜高。CD-SEM 計測の前処理そのもの。

## 選択課題 B — 周期的スキャンノイズの除去
- FFT でスペクトルを観察し、走査線由来の**周期ピーク**をノッチフィルタで除去する。
- 空間フィルタのみ / 周波数ノッチ / 併用を比較。ライン&スペースの周期（信号）を消さずに
  ノイズの周期だけ落とせるかを、スペクトルとプロファイルで確認する。
- 難易度: 中〜高（6〜7h）。

## 選択課題 C — エッジ保存平滑化の比較フレームワーク
- 複数手法を同一評価軸（PSNR/SSIM + エッジ保存 + 局所コントラスト + 処理速度）で横断比較する
  再利用可能なフレームワークを作る。
- 「ノイズ強度・保存要求ごとの推奨手法」を結論する。難易度: 中（5〜6h）。

## 評価ルーブリック（A 課題）

| 観点 | 不十分 | 十分 | 優秀 |
|---|---|---|---|
| 計測実装 | エッジ/線幅が算出できない | 線幅を算出できる | サブピクセル精度で安定 |
| 評価 | PSNR/SSIM のみ | タスク指向指標も算出 | 複数ノイズ強度で体系的に比較 |
| 考察 | 「きれいになった」で終わる | トレードオフを説明 | 手法選択の条件を一般化して説明 |
| 再現性 | 手元でしか動かない | ビルド・実行手順が明確 | seed 固定で完全再現 |
